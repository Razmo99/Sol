### Story

**As a Developer,** I want to initialize the `Sol` module with the `modulebuilder` layout and reorganize the existing functions into a standard `Public`/`Private` structure, **so that** the module is aligned with PowerShell best practices and is ready for future development.

### Acceptance Criteria

1.  A `Source` directory is created with `Public`, `Private`, `Classes`, and `Enum` subdirectories.
2.  A `build.ps1` script is created to automate the module build process.
3.  `build.prefix.ps1` and `build.suffix.ps1` files are created.
4.  The `New-CompanyUser` function is moved to the `Source/Public` folder.
5.  All helper functions from `Sol.psm1` are moved to the `Source/Private` folder.
6.  The existing module manifest (`Sol.psd1`) is copied and modified to list only `New-CompanyUser` as an exported function.
7.  The new module structure can be successfully built using `build.ps1` and the resulting module can be imported into a PowerShell session.

### Dev Notes

*   **ModuleBuilder Usage:**
    *   **Installation:** Ensure `modulebuilder` is installed (`Install-Module -Name ModuleBuilder`).
    *   **Structure:** Create the `Public` and `Private` folders for functions.
    *   **Build:** Use `Build-Module` to compile the module.
    ### Dev Notes

*   **ModuleBuilder Usage:**
    *   **Installation:** Ensure `modulebuilder` is installed (`Install-Module -Name ModuleBuilder`).
    *   **Structure:** The new source code will live in a `Source` directory. Inside `Source`, create `Public`, `Private`, `Classes`, and `Enum` folders.
    *   **Build Script:** Create a `build.ps1` file to configure and run `Build-Module`.
    *   **Build Files:** Create `build.prefix.ps1` and `build.suffix.ps1` files.
    *   **Manifest:** The existing `Sol/sol.psd1` should be copied to the new module root and updated. It should be modified to export only the `New-CompanyUser` function.

*   **Project Structure:** The new module structure should be created inside a `Source` directory.
*   **Function Organization:**
    *   The `New-CompanyUser` function should be considered public and moved to `Source/Public`.
    *   All other functions in the current `Sol.psm1` are helper functions and should be moved to the `Private` folder inside `Source`. Each function should be in its own `.ps1` file.
*   **Module Loading:** The main `Sol.psm1` file will be generated by the build process.
