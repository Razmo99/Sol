### Story

**As a** developer,
**I want** to execute `PSScriptAnalyzer` across the codebase and resolve all reported code smells and issues,
**so that** the code quality is improved and adheres to project standards. If any reported issues are deemed acceptable deviations from the standard, they should be documented and approved as exceptions.

### Acceptance Criteria

1.  `PSScriptAnalyzer` is executed against the entire codebase.
2.  No issues are reported by `PSScriptAnalyzer` after remediation, or all remaining reported issues have been explicitly documented and approved as exceptions.
3.  The codebase adheres to the established coding standards.

### Dev Notes

*   **Code Smells to Avoid:**
    *   Do not use `+=` to build collections in loops.
    *   Do not use aliases in scripts; use the full cmdlet name.
    *   Do not use `Write-Host` for logging; use the dedicated logging module.
    *   Do not hardcode configuration; these should be parameters.
    *   Do not use `Invoke-Expression`.
    *   [Source: architecture/coding-standards.md]

### Dev Agent Record

**PSScriptAnalyzer Issues Found:**

**Warnings:**
*   `PSUseSingularNouns`: Several cmdlets use plural nouns (e.g., `Assert-EMSUExists`, `Assert-Nodes`, `Test-PromptsWRequsOTHPrompts`, `Test-InteractivePrompts`, `Show-CompanyBranches`, `Sync-Directories`, `Assert-ADUExists`, `Test-Prompts`, `Set-ADUGroups`, `Assert-AADUExists`).
*   `PSUseProcessBlockForPipelineCommand`: `Assert-ADPermission.ps1`, `Assert-ADSyncPermission.ps1`, `Assert-EMSPermission.ps1` have the `CmdletBinding` attribute but no `process` block.
*   `PSPossibleIncorrectComparisonWithNull`: `Test-InteractivePrompts.ps1` has `$null` on the right side of equality comparisons.
*   `PSShouldProcess`: `Test-AADConnected.ps1`, `Assert-AADPermission.ps1` have `ShouldProcess` attribute but don't call `ShouldProcess/ShouldContinue`.
*   `PSAvoidAssignmentToAutomaticVariable`: `Get-TopologicalSort.ps1` assigns to the automatic variable `allNodes`.
*   `PSUseUsingScopeModifierInNewRunspaces`: `Sync-Directories.ps1` uses `$Server` in a script block without `Using:` scope modifier.
*   `PSAvoidUsingEmptyCatchBlock`: `Assert-AADUExists.ps1` has an empty catch block.
*   `PSReviewUnusedParameter`: `New-CompanyUser.ps1` has an unused parameter `SendToRecycleBin`.

**Information (mostly `PSAvoidTrailingWhitespace` and `PSUseOutputTypeCorrectly`):**
*   `PSAvoidTrailingWhitespace`: Many files have trailing whitespace.
*   `PSUseOutputTypeCorrectly`: Many cmdlets return objects but don't declare the `OutputType` attribute.

**Completion Notes:**
This story focused on cleaning up code smells and fixing `PSScriptAnalyzer` issues across the PowerShell codebase. All reported `Information` and `Warning` level issues were successfully addressed, including trailing whitespace, `PSUseOutputTypeCorrectly`, `PSUseSingularNouns`, `PSUseProcessBlockForPipelineCommand`, `PSAvoidAssignmentToAutomaticVariable`, `PSShouldProcess`, `PSAvoidUsingEmptyCatchBlock`, and `PSReviewUnusedParameter`.
