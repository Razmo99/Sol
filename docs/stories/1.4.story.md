### Story

**As a Developer,** I want to go through the existing `New-CompanyUser` function and replace all `AzureAD` and `MSOnline` cmdlets with their `Microsoft.Graph` equivalents, **so that** the module is fully migrated to the modern API before any structural refactoring takes place.

### Acceptance Criteria

1.  The `New-CompanyUser` function is modified to use the `Microsoft.Graph` PowerShell module for all interactions with Azure AD and Microsoft 365.
2.  All legacy `AzureAD` and `MSOnline` cmdlets are removed from the codebase.
3.  The function's core functionality remains equivalent to the original; it successfully creates a user in Azure AD and assigns licenses. **Note**: MFA configuration functionality is removed as part of this migration.

    *   **User Management**:

        *   `Set-AzureADUser -ObjectID $UPN -UsageLocation $Country` → `Update-MgUser -UserId $UPN -UsageLocation $Country`

*   **Required Graph Permissions (Scopes)**:
    *   `User.ReadWrite.All` - For user creation, modification, and license assignment
    *   `Directory.Read.All` - For reading organization and user information
    *   `Organization.Read.All` - For accessing subscription and license information

#### Specific Migration Examples from Codebase:

**Connection Management (Test-AADConnected.ps1:56-67)**:
```powershell
# Legacy Pattern
if ((Get-AzureADCurrentSessionInfo -ErrorAction Stop).Environment.Name -eq 'AzureCloud') {
    # Connected
}
Connect-AzureAD -AccountId $UserPrincipalName

# Microsoft.Graph Pattern
if ((Get-MgContext).Environment -eq 'Global') {
    # Connected  
}
Connect-MgGraph -Scopes 'User.ReadWrite.All','Directory.Read.All','Organization.Read.All'
```

**User Lookup (Assert-AADUExists.ps1:31)**:
```powershell
# Legacy Pattern
[bool]$Exists = Get-AzureADUser -ObjectId $UserPrincipalName -ErrorAction SilentlyContinue

# Microsoft.Graph Pattern  
[bool]$Exists = Get-MgUser -UserId $UserPrincipalName -ErrorAction SilentlyContinue
```

**License Assignment (Set-AADULicense.ps1:74-82)**:
```powershell
# Legacy Pattern (Object Model)
$LicenseInfo = Get-AzureADSubscribedSku | Where-Object -Property SkuPartNumber -Value $planName -EQ
$License = New-Object -TypeName Microsoft.Open.AzureAD.Model.AssignedLicense
$License.SkuId = (Get-AzureADSubscribedSku | Where-Object -Property SkuPartNumber -Value $planName -EQ).SkuID
$LicensesToAssign = New-Object -TypeName Microsoft.Open.AzureAD.Model.AssignedLicenses
$LicensesToAssign.AddLicenses = $License
Set-AzureADUserLicense -ObjectId $UserPrincipalName -AssignedLicenses $LicensesToAssign

# Microsoft.Graph Pattern (Hash Table)
$LicenseInfo = Get-MgSubscribedSku | Where-Object -Property SkuPartNumber -Value $planName -EQ
$addLicenses = @(@{SkuId = $LicenseInfo.SkuId})
Set-MgUserLicense -UserId $UserPrincipalName -AddLicenses $addLicenses -RemoveLicenses @()
```

**User Property Updates (Set-AADULicense.ps1:54)**:
```powershell
# Legacy Pattern
Set-AzureADUser -ObjectID $UserPrincipalName -UsageLocation $CountryCode

# Microsoft.Graph Pattern
Update-MgUser -UserId $UserPrincipalName -UsageLocation $CountryCode
```

**MFA Functionality Removal (Set-MSolUMFA.ps1:56-62)**:
```powershell
# Legacy Pattern (TO BE REMOVED)
$st = New-Object -TypeName Microsoft.Online.Administration.StrongAuthenticationRequirement
$st.State = $StrongAuthenticationRequirements
Set-MsolUser -UserPrincipalName $UserPrincipalName -StrongAuthenticationRequirements @($st)

# Microsoft.Graph Migration: FUNCTIONALITY REMOVED
```
